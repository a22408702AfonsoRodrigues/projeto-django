Arquitetura MVT do Django

O Django segue a arquitetura MVT (Model-View-Template):

  • Model -> define a estrutura dos dados e comunica com a base de dados
  • View —> recebe os pedidos, vai buscar os dados ao Model e envia-os para o Template
  • Template —> ficheiro HTML que apresenta os dados ao utilizador
